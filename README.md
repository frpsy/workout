# Rep Streak (일일 운동 체크)

푸시업·풀업·스쿼트(그리고 직접 추가한 운동)를 매일 체크하고, 주마다 목표를 조금씩 늘려 가는 기록장입니다.

- 주소: https://frpsy.github.io/workout/
- 예전 주소(frpsy.github.io/test/workout-check/)와 같은 브라우저라면 기록이 그대로 이어집니다.
- 폰에서 열고 **공유 → 홈 화면에 추가**를 하면 앱처럼 쓸 수 있습니다 (오프라인에서도 열림). 새로 배포되면 앱을 다시 볼 때 한 번 새로 불러와 최신 판이 됩니다(js/main.js 아래쪽 서비스 워커 등록).

## 기능

| 기능 | 설명 |
|---|---|
| 오늘 체크 | 종목별 목표(세트당 개수 × 세트 수, 기본 3세트 예: 15 × 3), 목표 옆 세트 번호(1·2·3)를 눌러 세트별로 체크(누른 세트까지 한 것으로 보고, 마지막 세트를 체크하면 종목 완료, 같은 번호를 다시 누르면 한 칸 되돌림), 오른쪽 원형 버튼은 일부만 마쳤을 때 진행(2/3)을 테두리로 보여 주고 누르면 한꺼번에 완료·해제, 세트당 실제 개수(− +는 1씩, 꾹 누르면 5씩 계속, 직접 입력도 가능)와 실제 세트 수 수정. 3종목과 최근 2주 달력이 한 화면에 들어옴 |
| 화면 보기 3단계 | 상태 줄 오른쪽의 요약/기본/상세 버튼. 요약은 이름·목표·완료 버튼만, 기본은 개수·세트 편집까지, 상세는 다음 주 목표 안내를 더하고 기록 자세히·앞으로 4주 목표를 펼침. 고른 단계는 이 브라우저에 기억 |
| 난이도 3단계 | 오늘 화면의 쉬움/보통/어려움 버튼으로 그날 목표를 0.8·1·1.2배로 바로 조절(초 단위는 5초 단위로 맞춤). 그날 기록에만 남고 이미 완료한 종목의 목표는 그대로 |
| 운동시간 | 오늘 화면 위쪽 ▶ 운동 시작을 누르면 시간이 흐르고, 중지/재개로 잠시 멈출 수 있고(멈춘 시간은 제외), ■ 종료를 누르면 그날 총 운동시간에 더해 기록(같은 날 여러 번이면 합산). 취소는 바로 기록 없이 버립니다. 기록된 그날 운동시간은 ‘초기화’로 바로 지울 수 있습니다. 오늘 체크한 세트·완료를 모두 되돌리면(체크가 하나도 없는 상태) 재던 시간과 기록된 운동시간도 함께 초기화됩니다. 새로고침·앱 재실행 뒤에도 이어서 재며, 기록 탭에서 오늘·최근 7일 운동시간을 확인 |
| 오늘의 마무리 | 그날 운동을 모두 마치면 오늘 화면에 ‘운동 소감’과 ‘감사한 일 한 가지’ 한 줄 칸이 나타남. 마지막 종목을 막 체크하면 칸이 화면으로 올라옴(포커스는 그대로). 쓰는 대로 저장(기기·계정 동기화 포함, 각 200자), ‘완료’를 누르면 짧게 접혀 보이고 접힌 내용이나 연필 버튼을 누르면 다시 씀. 쓰기 싫은 날은 ‘나중에’로 한 줄 버튼만 남김. 기록 탭 ‘마무리 기록’에서 최근 10개를 모아 봄 (js/ui/journal.js) |
| 휴식 타이머 | 오늘 화면의 한 줄 타이머: 시간 숫자를 누르면 30·60·90초 프리셋 3단계로 바로 바뀌고, −15/+15초로 세밀하게 조절(15초~10분, 마지막 값 기억) 후 시작·중지. 왼쪽 ‘휴식 자동/수동’ 버튼으로 세트 번호를 체크할 때 휴식이 자동 시작되게 할 수 있음(기본 자동, 되돌릴 때와 모든 운동을 마쳤을 때는 시작 안 함). 끝나면 소리·진동·표시, 실행 중에는 화면이 꺼지지 않게 요청 |
| 효과음 | 세트 체크(세트 번호에 따라 음이 올라감)·종목 완료·모두 완료·되돌림·운동 시작/종료·휴식 타이머 시작·중지음, 끝나기 3초 전 3·2·1 카운트, 끝나면 세 번 알림음(세트 체크로 자동 시작될 때는 시작음 없이). 파일 없이 Web Audio로 만들고, 상태 줄의 스피커 버튼으로 켜고 끄며 이 브라우저에 기억. 아이폰은 무음 스위치가 켜져 있으면 소리가 나지 않을 수 있음 |
| 모바일 | 더블탭 확대 지연 제거(touch-action), 입력 칸·메모 칸 16px(iOS 포커스 확대 방지), 난이도·화면 보기·효과음·자동휴식 버튼과 세트 번호의 눌리는 영역을 44px 안팎으로 넓힘, 누르는 즉시 살짝 눌리는 반응, 안전 영역(노치)·홈 화면 앱 지원 |
| 앱 같은 화면 | 아래 탭 3개(오늘 / 기록 / 설정). 오늘은 체크·스톱워치·휴식 타이머만, 기록은 달력·달성·연속·앞으로 4주 목표, 설정은 무음 모드 효과음·계정·목표·운동 목록. 달력에서 날짜를 누르면 오늘 탭으로 가서 그날 기록을 고침. 탭은 주소 뒤 #record 로 남아 새로고침·뒤로 가기에도 유지. 세 화면이 가로로 나란히 붙어 있어 옆으로 밀면 옆 화면이 함께 따라오고, 손을 떼면 관성대로 한 화면씩 붙음(토스 앱처럼, 브라우저 기본 가로 스크롤·스냅). 화면마다 세로 스크롤 위치를 따로 기억하고, 넘기는 도중에도 아래 탭 표시가 따라 바뀜. 보이지 않는 화면은 inert로 탭 키·화면 읽기에서 건너뜀. 운동 시간을 재는 동안(중지 중 제외) 화면이 꺼지지 않게 요청 |
| 시작 화면 | 앱을 열면 아이콘이 잠깐 깜빡 보였다가 준비되는 즉시 사라짐(기다리게 하는 최소 시간 없음). 1.2초 넘게 걸릴 때만 진행 막대와 문구(앱 준비 → 로그인 확인 → 기록 불러오기)가 나타나고, 8초 넘으면 연결이 느리다는 안내를 덧붙임. 로딩이 실패하면 ‘다시 시도’ 버튼 표시. 로그인한 계정은 지난번에 정상으로 열렸다면 서버 확인을 기다리지 않고 기기에 저장된 사본으로 먼저 열고 서버 값은 도착하는 대로 반영(읽기가 막히면 표시를 지워 다음 실행에서 다시 확인). 일반 브라우저에서는 불필요하던 0.8초 대기도 없앰 (js/boot-progress.js, js/storage/firebase.js) |
| 운동 팁 | 오늘 탭 아래 빈 곳에 낮게 팁 하나(30개 중 무작위, 열 때마다 바뀌고 누르면 다른 팁). 자세·호흡·회복·휴식·식물성 단백질과 비타민 B12 등 널리 알려진 일반 원칙만 담음 (js/tips.js) |
| 내일 날씨 | 팁 위에 한 줄(예: 내일 ⛅ 구름 조금 12°/22° · 비 20% · 서울). 외부 서비스 Open-Meteo(키 없는 무료 예보)에서 내일 하루치 요약만 받고, 기본은 서울 기준이며 줄을 누르면 내 위치로 바꿈(허용한 좌표는 이 브라우저에만 저장하고 예보 요청에만 사용). 같은 위치는 3시간 동안 저장해 둔 값을 써서 요청을 줄이고, 오프라인이거나 받지 못하면 줄을 숨김 |
| 초 운동 기록 | 단위가 초인 운동(플랭크 등)은 행의 시작/종료 버튼으로 시간을 재서 종료하면 그 세트의 실제 초로 자동 입력 |
| 목표 증가 | 매주 늘리기 / 해낸 주만 늘리기(주 N일 이상), N주마다 회복주 |
| 기록 | 맨 위에는 이번 주 달력만 보이고, 자세히를 펼치면 지난 4주 달력(날짜를 누르면 그날 기록 고치기, 쉬는 요일·목표 주차 시작일 표시), 모두 마친 날 수, 현재·최고 연속, 30일 달성률과 최근 7일, 종목별 연속·달성률(개수 합계는 보지 않음) |
| 계획 | 앞으로 4주 목표표 (접어 둠) |
| 운동 설정 | 추가·삭제·순서·단위(개/초)·세트 수·사용 여부, 추천 종목 빠른 추가, 쉬는 요일(기록이 없어도 연속 유지) |
| 계정 | 기록은 Google 로그인한 계정에만 보관(파일·복사 백업은 없음). 로그인 전에는 이 브라우저에만 임시 저장하고, 기록이 3일 넘게 쌓였는데 로그인하지 않았으면 오늘 화면에 로그인 안내(‘나중에’는 7일 숨김). 처음 로그인하면 이 브라우저 기록이 계정으로 옮겨짐 |

## Firebase로 기기 간 저장 켜기

기본은 브라우저 저장입니다. 아래를 하면 로그인한 계정에 저장되어 폰·PC가 같은 기록을 봅니다. 설정이 없으면 지금처럼 동작합니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **웹 앱**을 추가해 `firebaseConfig`를 확인합니다.
2. **Authentication → 로그인 방법**에서 Google을 켭니다. **설정 → 승인된 도메인**에 `frpsy.github.io`가 있는지 확인합니다 (기본 포함).
3. **Firestore Database**를 만들고(프로덕션 모드), **규칙**에 `firestore.rules` 내용을 붙여 게시합니다.
4. `js/firebase-config.js`의 `FIREBASE_CONFIG`에 1의 값을 붙여 넣고 커밋합니다. 이 값은 공개 식별자이며 데이터는 규칙이 지킵니다.
5. 앱 → 설정 → 계정 → **Google로 로그인**. 처음 로그인하면 이 브라우저의 기록이 계정으로 옮겨집니다 (계정에 기록이 이미 있으면 옮기지 않고 계정의 기록이 보입니다).

Firebase SDK는 `scripts/firebase-entry.js`를 묶어 `js/vendor/firebase.js`로 커밋해 둡니다 (오프라인에서도 동작). SDK 버전을 올렸다면 `npm run build:firebase`를 다시 실행하세요. CI가 최신 여부를 검사합니다.

## 확장하기

- **운동 기본값 바꾸기**: `js/config.js`의 `DEFAULT_EXERCISES`, `PRESETS`
- **단위 추가** (예: 미터): `UNITS`에 `{ label, inc }` 추가
- **증가 방식 추가**: `js/progression.js`의 `LEVEL_RULES`에 함수 추가 후 설정 화면 라디오 추가
- **저장소 추가** (예: Firebase로 기기 간 동기화): `js/storage/`에 같은 모양의 어댑터를 만들고 `storage/index.js`의 `createStorage()`에 연결
- **앱 파일 추가·삭제**: `npm run sw`로 `sw.js`의 `ASSETS`를 다시 만들기 (안 맞으면 `npm test`가 실패). 캐시 이름은 배포할 때 CI가 파일 내용으로 자동으로 정합니다. 글꼴은 `fonts/`에 있고 아티팩트 빌드만 Google Fonts를 씁니다
- **스타일 고치기**: 글자 크기는 `--fs-*`, 그림자는 `--shadow-*` 변수만 씁니다(`npm test`가 검사). 어두운 테마 색은 `style.css`의 두 블록(기기 설정·`data-theme`)에 똑같이 넣습니다(테스트가 같은지 검사). 화면이 바뀌면 안 되는 정리는 `npm run shots`로 확인합니다
- **저장 형식 변경**: `SCHEMA_VERSION`을 올리고 `model.js`의 `normalize*`에서 이전 형식을 변환
