# 상용 수준으로 가는 계획

목표: **집의 맨몸·철봉·아령과 회사·아파트 헬스장의 러닝머신으로 꾸준히 운동하는 앱.**
상용 운동 앱(Fitbod, Nike Training Club, Strong, Hevy, Streaks)이 공통으로 갖춘 것 가운데, 이 목표에 꼭 필요한 것만 다섯 단계로 나눠 넣습니다. 단계마다 PR 하나로 병합하고 배포까지 확인합니다.

| 단계 | 내용 | 상용 앱 기준 | 상태 |
|---|---|---|---|
| 1. 운동 도감 | 맨몸·철봉·아령 동작 29개, 자세 요령 한 줄, 더 쉬운·어려운 동작 연결, ‘내 기구’로 거르기 | 동작 라이브러리 | 완료 |
| 2. 아령 무게 | 종목별 kg 기록, 세트 기록에 무게, 반복 상한에 닿으면 무게 올리기 제안(이중 점진) | 무게 기록·점진적 과부하 | 완료 |
| 3. 러닝머신 | 속도·경사 프리셋, 속도×시간으로 거리 자동 계산, 나이를 넣으면 Zone 2 심박 범위 | 트레드밀 모드 | 완료 |
| 4. 시작 설정 | 처음 열면 기구 → 수준 → 주 횟수 세 질문으로 프로그램과 종목을 자동 구성 | 온보딩 | 완료 |
| 5. 꾸준함 장치 | 바쁜 날 최소 버전(2분 규칙), 이틀 연속 쉬지 않기 안내, 캘린더 일정(.ics) 내보내기, 누적 기록 배지 | 습관 앱의 핵심 장치 | 완료 |

## 다음 후보

- 휴대폰 실기기 점검(아이폰 홈 화면 앱): 시트·러닝머신 칸·캘린더 파일 열기
- 동작 영상·그림: 도감 동작마다 짧은 안내(저작권 문제 없는 자료만)
- 주간 돌아보기: 일요일 저녁에 한 주 요약과 다음 주 계획 한 줄

## 지키는 원칙

- 기존 기록과 설정은 그대로 둡니다. 새 필드는 없으면 예전처럼 동작합니다.
- 부상 예방이 먼저입니다. 동작 요령과 진행 규칙은 외부 AI 검수를 거칩니다.
- 화면은 그날 할 일만 크게 보이고, 나머지는 접습니다(군더더기 없이).
- 서버 없이 돌아가는 정적 웹앱이라 푸시 알림은 넣지 않고, 캘린더 일정으로 알림을 대신합니다.
