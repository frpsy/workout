# 설계·디자인 결정

이미 정해서 다시 뒤집지 않을 내용입니다. 바꾸려면 이 문서부터 고치고, 바꾸는 이유를 적습니다.

## 구조

- **빌드 없음**: 바닐라 JS ES 모듈을 GitHub Pages에서 그대로 엽니다. Firebase SDK만 `js/vendor/firebase.js`로 미리 묶어 커밋합니다.
- **계층**: 규칙(`day.js`·`setlog.js`·`progression.js`·`stats.js`, 순수 함수) → 상태(`store.js`) → 화면(`ui/*`). 화면은 상태를 받아 그리기만 하고, 기록을 바꿀 때는 `store.actions`를 부릅니다.
- **화면끼리 알림**: `events.js`의 이름(`EV`)으로만 주고받습니다. 새 이벤트는 그 파일 맨 위 목록에 먼저 적습니다.
- **저장 형식은 덧붙이기만**: 하루 기록에 필드를 더할 때 기존 필드는 그대로 둡니다(예: 세트 기록 `log`). 예전 판을 연 기기가 같은 날짜를 저장해도 완료·연속 기록은 깨지지 않습니다. 저장 형식을 통째로 바꾸는 v3는 이 이유로 하지 않았습니다.
- **기록 전체를 구독**: Firestore에서 날짜별 문서를 모두 받습니다. 최고 연속·모두 마친 날 수 계산에 전체 기록이 필요하고, 하루 한 문서라 양이 적습니다.

## 기록

- **백업 파일 없음**: 기록은 Google 로그인한 계정에만 둡니다. 파일·복사 백업 화면은 일부러 뺐습니다(테스트가 없는지 검사).
- **세트 기록**: 세트를 마칠 때의 세트당 개수를 한 줄씩 남깁니다. 완료 여부는 계속 `entries`가 기준이고, `log`는 세트별 개수·총 개수에만 씁니다.
- **정상 저장은 조용히**: ‘저장 중’·‘저장했습니다’ 문구를 보이지 않습니다. 4초 넘게 동기화를 기다릴 때와 실패만 알립니다.

## 화면

- **휴식 타이머는 크기가 바뀌지 않음**: 쉬는 중에도 높이·배치는 그대로이고 색과 얇은 진행 막대로만 강조합니다(#145).
- **맨 위는 색 띠 없이**: 상태 표시줄 영역을 색 띠로 구분했다가 되돌렸습니다(#138 → #139). 선·간격·굵기로만 구분합니다.
- **디자인 값은 변수로만**: 글자 크기 `--fs-*`, 간격 `--gap-*`, 모서리 `--r-*`, 그림자 `--shadow-*`. 테스트가 검사합니다.
- **화면이 바뀌면 안 되는 정리**는 `npm run shots`로 기준 커밋과 픽셀 비교하고, 화면을 바꾼 작업 뒤에는 `npm run check:iphone`을 돌립니다.

## 오늘 화면

- **운동 시간 자동 시작은 회차마다**: 처음에는 오늘 운동 시간이 한 번이라도 기록돼 있으면 자동 시작하지 않아, 두 번째 회차(‘한 번 더 하기’ 뒤 취소 등)에서 세트를 체크해도 시간이 흐르지 않았습니다. 이제 지금 회차의 첫 체크면 시작하고, 회차 도중 일부러 멈춘 경우만 다시 켜지 않습니다.

- **지금 할 종목 하나에 집중**: 아직 마치지 않은 첫 종목만 크게 펼치고(사용자가 남은 종목을 누르거나 체크하면 그 종목으로 바꿈. 운동 순서를 그때그때 고를 수 있게)(목표 40px, 폭 전체 56px 완료 버튼), 마친 종목·남은 종목은 한 줄로 접습니다. 화면에서 강조하는 것은 이 한 곳뿐이고, 나머지 장식은 더하지 않습니다.
- **기본/상세 보기 없음**: 상태가 화면을 정하므로 보기 전환 버튼을 없앴습니다. 조절 줄은 ⌄로 엽니다.
- **머리말은 두 층 + 진행**: 앱 줄 오른쪽 끝에 날짜, 그 아래 주차 안내와 운동 버튼. 효과음 버튼은 설정 탭에 둡니다.
- **종목을 마치면 다음 종목으로**: 한 종목의 마지막 세트를 체크하면 다음 종목이 펼쳐지고 화면이 그 줄로 넘어갑니다(휴식 타이머에 가리지 않게). 종목 사이 휴식은 세트 사이 시간과 따로 기본 1분입니다(`EXERCISE_REST_SEC`). 이미 쉬는 중이면 새로 시작하지 않습니다.
- **머리말 진행은 ‘종목’으로**: 머리말의 ‘0/3’은 마친 종목 수라 ‘0/3 종목’으로 씁니다. 큰 완료 버튼의 ‘1/3’(세트)과 같은 모양이라 ‘완료’로 쓰면 헷갈렸습니다.
- **회차를 마치면 휴식 타이머 숨김**: 더 쉴 세트가 없는데 ‘휴식 시작’이 크게 남아 마무리·한 번 더 하기에서 눈을 빼앗았습니다.
- **운동 시간 초기화는 지금 재는 시간만**: 사용자 요청으로, 이미 기록된 운동시간(앞 회차 등)을 지우는 ‘시간 초기화’ 버튼(#157의 두 번 눌러 지우기 포함)을 없앴습니다. 재는 동안의 ‘취소’를 ‘초기화’로 부르고, 지금 재는 시간만 기록하지 않고 버립니다.
- **잘못 기록된 운동 시간은 설정에서**: 오늘 화면에는 지우는 버튼을 두지 않고(실수로 누르기 쉬움), 설정 맨 아래 ‘운동 시간 기록’에서 날짜별로 지웁니다. 되돌릴 수 없어 같은 버튼을 3초 안에 한 번 더 눌러야 지우고, 세트 체크 기록은 건드리지 않습니다. 시간은 분 단위로 직접 고치거나 빠뜨린 날에 넣을 수도 있습니다. 고쳐도 실제로 잰 시작·종료 구간은 지우지 않고 그대로 둡니다(멈춘 시간이 빠지므로 원래도 구간과 합계가 꼭 같지 않고, 지우면 되돌릴 수 없음). 목록은 처음엔 최근 14일만 보이고 ‘전체 보기’로 펼칩니다. 넣을 때는 이미 있는 날에 더합니다.
- **진한 초록은 큰 완료 버튼 하나**: 쉬기 전 휴식 타이머의 ‘휴식 시작’도 진한 초록이라 ‘N세트 완료’와 시선을 나눴습니다. 휴식은 세트를 마치면 자동 시작되므로 옅은 초록으로 낮췄습니다. 세트 점의 ‘다음 세트’는 회색으로 칠하면 마친 세트처럼 보여 칠하지 않은 고리로 바꿨습니다.
- **휴식 타이머는 탭 막대 바로 위**: 내용이 짧아도 아래로 붙여 빈 띠를 두지 않습니다.

- **순서는 오늘 화면에서도 바꿈**: 운동 중에 기구가 비어 있지 않거나 컨디션이 달라 순서를 바꾸고 싶을 때 설정 탭까지 가지 않게, 줄을 길게 눌러 끌어 옮깁니다(손잡이 아이콘 없이 평소 줄은 그대로 단순하게, 누르자마자 움직이면 스크롤과 구분). 키보드·화면 읽기용으로 펼친 종목에만 작은 ↑↓도 둡니다. 설정에도 같은 순서로 저장됩니다.

## 마무리 쓰기

- **다 쓴 뒤에는 한 줄만**: 오늘 화면은 운동하는 곳이라, 써 둔 소감·감사를 펼쳐 두면 끝난 화면이 길어지고 ‘한 번 더 하기’와 시선을 다툽니다. 내용은 기록 탭 그날 카드에서 보고, 오늘 화면에는 ‘썼어요’ 한 줄(누르면 고침)만 둡니다. 쓰는 대로 저장되므로 ‘완료’·‘나중에’를 나누지 않고 ‘접기’ 하나로 합쳤습니다.
- **끝난 화면은 조용하게**: 운동을 마친 뒤에는 더 할 일이 거의 없으므로 진한 초록 버튼·색 띠·카드를 걷어 냈습니다. ‘한 번 더 하기’는 옅은 초록 버튼, 마무리 줄은 카드 없는 글자, 마친 종목의 ✓는 바탕 없이 표시만 합니다.
- **쓰는 칸은 화면 맨 위로**: 화면 전체가 고정(`.pager`)이라 iOS가 입력 칸을 키보드 위로 끌어올리지 못합니다. 포커스 순간 앱이 직접 마무리 칸을 맨 위로 올리고(`html.typing`, `js/ui/journal.js`), 키보드는 그 아래에 오게 합니다.

## 기록 화면

- **카드는 맨 위 하나**: 달력과 고른 날 기록을 한 카드로 묶고, 그 아래 통계는 카드 없이 구분선으로 나눕니다. 모든 묶음을 같은 카드로 쌓으면 무엇이 중요한지 보이지 않기 때문입니다.
- **볼륨은 막대로**: 최근 7일 총 개수는 문장 대신 종목별 하루 막대 7개와 합계·증감으로 보여 줍니다.

## 화면 켜짐

- **앱이 열려 있는 동안 늘 켜 둠**: 처음에는 스톱워치·휴식 타이머가 돌 때만 화면 꺼짐을 막았지만, 세트 사이에 기기를 만지지 않는 시간이 길어 타이머를 켜지 않은 채 화면이 꺼지는 일이 잦았습니다. 사용자 요청으로 앱이 화면에 보이는 동안에는 늘 막습니다(`js/main.js`). 다른 앱으로 가면 브라우저가 풀어 배터리 부담은 앱을 보고 있는 시간에 한정됩니다.

## 소리

- **다른 앱 소리를 멈추지 않음**: 기본은 유튜브·음악 위에 섞여 나는 소리(ambient)입니다. 무음 모드에서도 소리를 내는 설정을 켜면 다른 앱 소리가 멈출 수 있습니다.
