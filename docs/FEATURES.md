# 기능 상세

화면마다 실제로 어떻게 동작하는지 적은 문서입니다. 기능을 바꾸면 이 표를 함께 고칩니다. 바꾸게 된 이유는 [DECISIONS.md](DECISIONS.md)에 남깁니다.

| 기능 | 설명 |
|---|---|
| 집중형 오늘 화면 | 종목 줄은 세 상태로 보임: 지금 할 종목(기본은 아직 마치지 않은 첫 종목. 남은 종목의 이름·목표를 누르거나 그 종목을 체크하면 그 종목이 지금 할 종목이 되고, 그 종목을 마치면 다시 마치지 않은 첫 종목으로. 그날만 기억) 하나만 크게 펼쳐 목표 개수를 가장 큰 글자(40px)로, 완료 버튼을 폭 전체·높이 56px(‘2세트 완료 1/3’)로 보여 주고, 마친 종목(옅은 바탕·흐린 글자)과 남은 종목은 이름·목표·세트 수(‘23개 ×3’)만 한 줄(52px)로 접음. 남은 종목도 오른쪽 작은 버튼으로 바로 체크 가능. 개수·세트 조절 줄은 ⌄(또는 지금 할 종목·마친 종목의 이름·목표)를 눌러 편 종목에만 보이고, 키가 760px 이상인 화면에서는 지금 할 종목의 조절 줄을 펴 둠. 세트를 마친 순간 그 세트의 점 하나만 살짝 튐(움직임 줄이기 설정이면 없음). 기본/상세 보기 버튼은 없앰 |
| 한 번 더 하기 | 그날 다 한 뒤에도 더 할 수 있음. **근력**: 근력 화면에서 모두 마치면 ‘1회차를 마쳤어요 · 운동 한 번 더 하기’(기존 회차 기능). 2회차를 시작하면 근력 화면은 다시 0/N부터지만, 홈 카드는 회차를 합쳐 ‘✓완료’를 지키고 ‘2회차 하는 중 · 1/4’로 보여 줌. **달리기**: 달린 뒤 달리기 화면에 ‘한 번 더 달렸나요? +10분 · +20분 · +30분’. 누를 때마다 달리기 한 번을 더하고(`day.run.more`, 하루 9개까지) 목록에 ‘2회 20분 ✕’, 오른쪽에 ‘오늘 3회 · 합계 1시간’. 더한 시간·거리는 이번 주 습관·달리기 누적·이정표·기록 탭에 모두 더해지고(달린 날 수는 하루 1), 기록 탭 그날 카드에 ‘한 번 더 20분 (합계 50분)’. 홈의 끝난 카드에는 ‘＋ 한 번 더’ 표시 |
| 스톱워치로 달리기 기록 | 달리기 화면에서 ‘운동 시작’으로 시간을 재고 종료하면 ‘방금 잰 25분으로 달리기 기록’(이미 달렸으면 ‘한 번 더로 기록’) 버튼이 나옴. 한 번 누르면 기록되고 버튼은 사라짐(근력 화면에서 잰 시간은 쓰지 않음) |
| 이번 주 칸 | 홈 맨 아래 월~일 7칸. 날마다 근력(파랑)·달리기(초록) 점: 했으면 채우고, 계획이면 테두리만. 오늘은 굵게, 남은 날은 흐리게. 끊기지 않는 사슬이 보이게 함 |
| 지난주 돌아보기 | 프로그램을 쓰면 월~수요일 홈 맨 위에 ‘지난주 근력 3/3회 · 달리기 150/150분 · 계획의 100%’와 한마디(80% 이상이면 ‘잘 지켰어요’, 아니면 ‘바쁜 날 버튼으로라도 이어 가요’). ‘확인’을 누르면 그 주에는 숨김 |
| 쉬는 날 안내 | 근력·달리기 계획이 모두 없는 날, 홈에 ‘오늘은 쉬는 날이에요. 가볍게 걷거나 스트레칭하면 내일이 더 가벼워요.’ 모두 마친 날의 ‘오늘 할 일을 모두 마쳤어요’ 뒤에는 연속 일수(‘· 연속 5일’) |
| 스트레칭 | 오늘 화면의 운동 목록 위에 ‘운동 전 스트레칭’, 아래에 ‘운동 후 스트레칭’ 한 줄 버튼. 하고 나서 누르면 옅은 포인트 색 바탕에 ✓(안 했을 땐 윤곽선), 다시 누르면 취소. 그날 기록(day.stretch = { pre, post })에 남고 기록 탭 그날 카드에 ‘스트레칭 운동 전 · 후’로 보임. 운동 완료·진행률·연속 일수에는 영향 없음. 지난 날을 보는 중에도 고칠 수 있음 |
| 달리기(Zone 2) | 오늘 화면의 달리기 카드: 머리 줄(‘달리기 Zone 2’, 오른쪽에 목표 또는 결과·페이스, 완료 뒤 ↶) → 근력의 세트 완료처럼 큰 **‘45분 달리기 완료’** 버튼(높이 56px, 계획이 없으면 ‘달리기 완료’) → 시간 프리셋 20·30·45·60분. 완료 버튼은 계획한 시간으로 한 번에 기록하고, 다시 눌러도 지워지지 않음(지우기는 ↶만). 시간 프리셋을 누르면 그 시간으로 바로 완료되고, 다시 눌러도 지우지 않음(지우기는 ↶만). 완료하면 카드가 옅은 민트 초록로 채워지고 ‘✓ 달리기 완료’로 바뀌며 거리 프리셋 3·5·7·10km와 시간(분·초)·거리 직접 입력 칸이 열림(`day.run = { done, sec, km }`). 계획이 있으면 민트 초록 테두리. 근력 완료·진행률·연속에는 영향 없음. 기록 탭: 달린 날 달력 점(민트 초록), 그날 카드 ‘달리기’ 꼬리표, ‘달리기’ 묶음(최근 7일 막대, 연속·최고 연속, 이번 달·누적 합계·평균 페이스) (js/run.js) |
| 러닝머신 | ‘내 기구’에 러닝머신이 있으면(고른 적 없으면 있다고 봄) 달리기 완료 뒤 거리 프리셋 대신 속도 프리셋 6·7·8·9km/h와 속도·경사(%) 칸이 열림(`day.run.speed`·`incline`). 속도를 넣으면 거리가 속도 × 시간으로 채워지고, 시간을 바꾸면 거리도 다시 계산(거리를 직접 고치면 그 값이 남음). 같은 속도를 다시 눌러도 지우지 않음. 요약은 ‘45분 · 5.63km · 7.5km/h · 경사 1%’(러닝머신은 페이스 대신 속도). 설정 ‘목표’의 나이(선택, `config.age`)를 넣으면 달리기 안내가 ‘심박 108~126회/분 · 숨이 조금 차도…’로 바뀜(최대 심박 220 − 나이의 60~70%). 러닝머신이 없으면 예전처럼 거리 프리셋 |
| 시작 설정 | 처음 쓰는 사람(기록·프로그램 없음)에게 오늘 화면이 열릴 때 한 번, 아래에서 올라오는 시트(js/ui/onboard.js)로 두 가지를 물음: ① 집에 있는 기구(철봉·아령·러닝머신) ② 지금 내 수준(처음이에요 → 입문, 조금 해 봤어요 → 균형, 달리기를 더 하고 싶어요 → 지구력). 고르는 대로 아래 미리보기(‘입문 · 근력 주 2회 · 달리기 주 90분’, 추천 운동 이름 × 세트)가 바뀜. ‘이대로 시작’을 누르면 프로그램·내 기구·시작일(오늘)을 정하고, 운동 목록을 밀기·당기기(기구가 있을 때)·하체·엉덩이·코어 하나씩으로 새로 만듦(처음이면 가장 쉬운 단계·2세트, 해 봤으면 한 단계 위·3세트, 아령 동작은 5kg부터)(js/onboard.js). ‘나중에’·Esc는 아무것도 바꾸지 않음. 한 번 지나가면 다시 뜨지 않고(`workout-check:onboard`), 오늘 화면 프로그램 안내의 ‘고르기’와 설정 ‘운동 프로그램’의 ‘두 가지 질문으로 맞춤 구성 받기’로 다시 열 수 있음. 기록이 있는 사람은 ‘운동 목록도 이 구성으로 바꾸기’를 켤 때만 목록을 바꾸며, 같은 동작은 그 종목을 그대로 쓰고(연속 유지) 나머지는 지우지 않고 ‘사용 안 함’으로 남김. 합쳐서 12개를 넘으면 바꾸지 않고 이유를 알려 줌 |
| 운동 프로그램 | 설정 맨 위 ‘운동 프로그램’ 카드 세 장: 입문(근력 월·금, 달리기 화·목·토 30분, 주 90분), 균형(근력 월·수·금, 달리기 화·목 45분·토 60분, 주 150분), 지구력(근력 화·목, 달리기 월 30분·수·금 45분·일 75분, 주 195분). 카드마다 한 주를 요일 칸(근력 파랑·달리기 분 민트 초록·쉼)으로 보여 줌. 누르면 바로 적용·저장: 근력하지 않는 요일은 쉬는 요일이 되어 근력 연속이 끊기지 않고, 요일별 달리기 목표(`config.runPlan`)가 생김. 고른 카드에 ‘사용 중’, 다시 누르면 해제(쉬는 요일은 그대로, 달리기 목표는 지움). 쉬는 요일을 직접 고치면 ‘사용 중’ 표시만 풀림. 프로그램을 쓰면 오늘 화면 맨 위에 ‘오늘 할 일’이 보임 (js/program.js) |
| 홈과 운동 화면 | 오늘 탭은 세 화면으로 나뉨(`data-mode`). **홈**: 머리(날짜·주차) 아래 ‘근력’·‘달리기’ 큰 카드 두 장만. 카드마다 할 일(근력 ‘1/4’과 진행 막대, 달리기 ‘45분’), 끝나면 옅은 바탕과 ‘✓완료’, 그날 하지 않으면 점선 테두리로 흐리게(‘쉬는 날’·‘자유’). 달리기만 하는 날은 달리기 카드가 위. 계획한 것을 모두 마치면 위에 ‘오늘 할 일을 모두 마쳤어요’. 그 아래 ‘두 번 연속 쉬지 않기’ 안내와 바쁜 날 한 줄. **근력 화면**: 카드를 누르면 ‘‹ 오늘 · 근력 · 1/4’ 머리 아래 스톱워치·난이도·진행, 스트레칭, 종목, 휴식 타이머만. 근력 쉬는 날에는 ‘오늘은 근력 쉬는 날이에요’ 안내와 함께 그대로 할 수 있음. 모두 마치면 ‘근력 끝 · 오늘 화면으로’ 버튼. **달리기 화면**: ‘‹ 오늘 · 달리기 · 목표 45분’ 머리 아래 달리기 카드만, 완료하면 ‘달리기 끝 · 오늘 화면으로’. 운동 화면에서는 옆으로 밀어도 탭이 바뀌지 않음(누르다 화면이 흔들리지 않게). 마무리 칸은 홈에서만, 휴식 타이머는 근력 화면에서만 보임 |
| 프로그램 안내 | 운동 프로그램을 아직 고르지 않았으면 오늘 화면 머리말 아래에 ‘프로그램을 고르면 할 일이 정리돼요 · 고르기 · 나중에’ 한 줄(로그인 안내가 보일 때는 숨김). ‘고르기’는 설정의 운동 프로그램으로, ‘나중에’는 14일 숨김(이 브라우저에만 기억) |
| 이번 주 습관 | 기록 탭 맨 위. 월~일 칸마다 계획한 운동을 테두리 동그라미(근력 파랑·달리기 민트 초록)로, 한 운동은 채운 동그라미로(계획에 없던 날 더 한 운동은 점선, 계획이 없는 날은 ‘쉼’), 오른쪽에 오늘까지의 ‘계획 3/4 · 75%’(오늘은 이미 한 것만 셈). 그 아래 벤토: ① 이번 주 링(Apple 피트니스처럼 바깥 근력 횟수·안쪽 달리기 분, 계획을 채우면 링이 닫힘)과 숫자, 지난주 같은 요일까지와의 비교(늘었으면 ‘지난주 이맘때보다 달리기 +15분’, 줄었으면 지난주 값만 담담하게) ② 습관 연속(계획을 80% 이상 지킨 주가 이어진 수) ③ 달리기 누적 시간·횟수·거리. 요일 칸을 누르면 아래 카드에 그날 기록을 보여 주고 그 칸에 파랑 테두리. 기록이 하나도 없고 프로그램도 없으면 숨김 |
| 바쁜 날 | 프로그램을 쓰는 날, 오늘 할 일 아래 조용한 한 줄 ‘시간이 없는 날엔 · 1세트·10분만 하기’(근력만이면 ‘1세트만’, 달리기만이면 ‘10분만’, 어제를 놓쳐 ‘두 번 연속 쉬지 않기’ 안내가 떠 있으면 앞말 없이 버튼만). 누르면 그날만 바쁜 날(`day.mini`): 종목마다 1세트만 하면 완료, 달리기 목표·완료 버튼·오늘 할 일이 10분으로 바뀌고, ‘세트 -2’ 같은 차이 표시는 나오지 않음. 켜면 옅은 바탕에 ‘바쁜 날 · 근력 1세트 · 달리기 10분 · 되돌리기’. 그날 할 일을 다 하면 숨김. 이렇게 마친 날도 완료·연속·이번 주 습관에 똑같이 셈 |
